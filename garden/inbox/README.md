# inbox/ — a tray, not a shelf

Drop things here when you have not decided yet. Move them to `../raw/` when you have.

An empty inbox is the healthy state. Nothing in here is stored — if it matters, it
belongs in `raw/`.

If you use Claude, say **"process the inbox"**. It opens each file to find out what it really
is, copies it into `raw/` untouched with a real title, rebuilds the index, and only then
removes it from here — never before the copy in `raw/` is checked byte for byte.
